## 已修正

- 快速 PDF 会等待打印区域的图片就绪，并在系统结束打印后退出预览。缺图会提示具体资源。在没有结束事件的浏览器中，可以用预览页的返回按钮退出。
- HTML 按每张图片的实际来源嵌入，重复图片复用结果，保留角色文字，图片嵌入失败时会提示原因。超时经正常错误流程退出。
- HTML 与 JSON 的下载地址在浏览器有时间接手后才释放。JSON 可直接从角色数据导出，含头像的文件使用 Blob 下载。
- 未选职业的角色卡可以重新导入。HTML 中的角色文字包含标签或旧版数据分隔符时，可以完整回读。

本次验证针对普通浏览器网页与离线文件。不同厂商内置浏览器对系统下载和打印的支持仍有差别。
