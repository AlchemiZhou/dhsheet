# 相对原版，最值得介绍的更新

按对玩家的实际价值排序，省略内部修复和按钮微调；不把原项目已有能力说成从零开发。

1. **13 职业 A4 成品导出。** 前两页接入提供的彩色版式，角色资料自动带入；卡牌继续带插图。彩色／黑白 PDF 有独立入口。游侠伙伴页也接入对应版式，使用正方形头像。
2. **完整种族双特性＋可切换混血。** 默认关闭混血，选择完整种族，同时获得两项特性；开启后分别混搭。选择器完整展示插图，桌面每行三张。
3. **扩展资源、转变与武术架势。** 内嵌 Hope & Fear 资源与扩展职业；转变默认关闭，选中的转变卡随角色导出。可选武术架势页记录 16 种架势、当前架势与专注点。
4. **职业驱动的建卡辅助。** 推荐属性、主副武器和护甲可自动匹配，可关闭。领域卡先筛对应两个领域，支持撤回与重做。
5. **新增：引导问答与自由写作并存。** 背景栏可切换自由背景，关系栏可切换角色介绍，两栏独立。问答与自由文本分别保留，可由已有回答生成草稿，提供专注写作。导出跟随当前版式，长文保留可读字号并在文末附全文。
6. **新增：手机装备卡片。** 武器与护甲使用竖向卡片，直接阅读完整属性与特性，保留来源、搜索与筛选，再用明确按钮选择。
7. **职业双色与手机布局。** 13 职业按各自两个领域配色，同一领域跨职业保持同色；支持跟随职业、保持默认或固定职业配色，六项属性仍使用中性色。

来源：基于 RidRisR 的原开源车卡器继续改造。规则、卡面插图与原版模板并非本次原创。
