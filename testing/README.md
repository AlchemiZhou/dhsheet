# 混血开关与完整种族卡测试版

下载本目录的 DHSheet-test.zip，解压全部文件，用 Chrome 或 Edge 打开“车卡器入口.html”。

本次更新：
- 混血开关改为带背景、边框、状态颜色和滑块的按钮。
- 关闭混血时，选择窗口中的一张完整种族卡包含两个具名特性及各自的完整效果说明。
- 角色卡牌区、悬停预览与钉住窗口也会展示完整种族卡。
- 开启混血后恢复独立选择两项特性，关闭后以第一项种族配齐第二特性。
- 底层两项特性仍分别保存和驱动自动效果，保留已有角色数据。

测试步骤：新建测试角色，选择种族，检查两个特性；切换混血开关；到第二页查看种族卡，并尝试悬停和钉住。
