## 如何试用

1. 下载本目录的 `DHSheet-test.zip`，完整解压到一个新文件夹。
2. 打开解压后的 `车卡器入口.html`。不要在压缩包中直接运行，也不要只移动 HTML 文件。
3. 若需要扩展卡牌，请在底部“扩展”中自行导入原资源包。本下载不包含用户上传的资源包。
4. 重要角色建议先用原版本“存档”导出备份。旧版本入口和文件可以保留。

这是测试分支的独立版本，未合并 main，也未部署到正式网站。
