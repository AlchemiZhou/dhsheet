# 匕首心车卡器测试版 v7

本版已内置用户提供的《匕首之心：希望与恐惧》玩家资源 1.1.0，无需手动导入扩展包。

包含全部 352 张扩展卡和 73 张原始插图：
- 4 个扩展职业：刺客、格斗家、灵巫、邪术师。
- 12 张种族特性卡（6 个种族）、6 张社群卡、24 张子职业卡、21 张领域卡。
- 285 张杂项卡，其中有 6 张转变卡：半神、变形者、吸血鬼、复生者、狼人、鬼魂。

插图随下载包保存，通过相对路径读取，无需网络或导入图片数据库。源包没有提供插图的卡牌使用原有占位图。卡牌 ID、名称和规则原文保持不变。

此前已经导入过同 ID 扩展卡的用户继续使用原导入内容，保留编辑、图片及禁用状态，避免重复加载。已有角色卡实例不会被内置模板覆盖。

## 使用方法

1. 下载 `DHSheet-test.zip`，完整解压到一个新文件夹。
2. 打开解压后的 `车卡器入口.html`。不要在压缩包内直接运行，也不要只移动 HTML 文件。
3. 直接选择扩展职业；开启“转变”后点击选择框，即可选择 6 张转变卡。
4. 重要角色建议先在旧版本中通过“存档”导出备份，再在新版载入。

仍包含默认关闭的混血/转变、双特性种族卡、三列种族选择、13 职业双色主题、12 格生命/压力上限，以及彩色/黑白导出。

本版位于测试分支，未合并 main，也未部署到正式网站。
