# 匕首心车卡器测试版 v9：第一页打印修复

修复内容：
- 恢复打印时顶部深色信息栏、六项属性及装备栏的深色标题与边框；浏览器关闭“背景图形”时仍保持清晰。
- 职业特性区在打印时按正文高度展开，不再使用屏幕上的 250px 固定滚动框。框底不会单独溢出到额外纸张，也不裁掉规则正文。
- 生命、压力及其他标记保持原有线宽，避免打印样式把选中标记边框强行加粗。
- 修复独立 HTML 带着旧版 CSS 导出的问题：现在构建前会生成当前样式，正确保留顶部三列布局和每行六格的资源分组。
- 独立 HTML 保持勾选框原尺寸，页边距与应用一致，并保留生命/压力上限等“仅打印时显示”的数值。

## 如何使用

下载 `DHSheet-test.zip`，完整解压到新文件夹，打开 `车卡器入口.html`。用原角色存档在新版重新导出 PDF 或独立 HTML；旧 PDF、旧独立 HTML 不会自动更新。

重要角色先通过旧版“存档”备份，再载入新版。不要只移动入口 HTML，也不要在压缩包内直接运行。

仍包含内置的 352 张希望与恐惧扩展卡及 73 张插图、混血/转变、职业双色、12 格生命/压力、可选武术架势页和自定义 credit。
