## 武术架势怎么用

1. 点击角色卡顶部的“+ 页面管理”，开启“武术架势”。默认关闭，不会改变其他可选页面开关。
2. 点击名称前的圆圈标记已掌握架势。首次从位阶 1 选择两种，之后每升一级可多选一种当前或更低位阶的架势。
3. 用顶部 6 个圆圈记录专注点，按规则掷骰后填写结果。
4. 点击已掌握架势的“激活 · 1 专注”，扣除 1 点专注并将其设为当前架势；切换会替换旧架势。
5. 严重伤害或场景结束时点击“退出架势”。标满生命时会自动退出。架势特性的掷骰与效果按正文结算。
6. 掌握记录、当前架势、专注点和页面开关均随角色保存，支持 JSON/HTML 存档及 PDF/独立 HTML 导出。

## 使用测试版

完整解压本目录的 `DHSheet-test.zip` 到一个新文件夹，打开 `车卡器入口.html`。
不要在压缩包内直接运行，也不要只移动 HTML 文件。重要角色先在旧版本通过“存档”备份，再载入新版。

仍内置全部 352 张《匕首之心：希望与恐惧》扩展卡和 73 张原始插图，包括 6 张转变卡，无需手动导入。
仍保留默认关闭的混血/转变、完整双特性种族卡、三列种族选择、13 职业双色主题、彩色/黑白打印。
