# 转变卡与职业双色主题测试版

下载 DHSheet-test.zip，完整解压到新文件夹，用 Chrome 或 Edge 打开“车卡器入口.html”。

## 本次功能
- 非混血种族卡：桌面宽屏每行 3 张，保留完整插图和双特性。
- 顶部右侧新增“转变”，默认关闭；开启后可以选择一张转变卡。选中的卡占一个普通聚焦卡位，导出时默认作为一张卡；更换不会重复加入，关闭会移除该卡。
- 职业双色主题自动跟随职业。底部“更多 → 车卡器配色”可选择跟随职业、保持默认配色、指定某职业配色。
- 打印预览底部“打印设置”可选择彩色或黑白；黑白主色 #303030、副色 #707070。
- 六项属性保持统一中性色。领域配色与 13 个职业映射集中管理，配色设置独立于角色存档。

## 导入扩展包
新提供的 Hope_Fear_Player_Resources_With_Images (1).zip 不包含在此应用压缩包内。请在应用底部点击“扩展 → 选择文件”，导入你提供的 ZIP，然后返回主站打开“转变”。
资源包实际导入测试：352 张卡；73 个图片绑定可解码；6 张转变卡（半神、变形者、吸血鬼、复生者、狼人、鬼魂）的插图、双特性、选择、更换、刷新恢复及单卡导出均已核对。现有旧格式导入器会显示 2240 条兼容提示，转变卡的完整效果文本与图片未丢失。
