# DHSheet 测试版 v10：手机适配

本版在 v9 打印修复版上增加响应式编辑布局，保留此前的种族双特性、混血、转变、职业双色、内嵌扩展包和武术架势。

## 打开

将压缩包解压到新的文件夹，电脑上打开“车卡器入口.html”。已有角色请通过存档管理导入原存档；原文件夹和存档可继续保留。

手机浏览器访问使用本分支部署的页面时，将自动使用手机布局，无需设置。手机文件管理器的 HTML 预览并不等于运行网站，建议使用浏览器访问页面。

## 手机操作

- 顶部信息、人物数值、装备、库存按屏幕宽度重新排列。
- 生命、压力、希望、护甲、熟练度、金币等标记提供更大的触屏点击区域。
- 页面标签和卡牌类型栏可左右滑动。窄屏卡牌选择为单列，中等屏幕两列，桌面仍保留三列种族卡。
- 底部五个入口：卡牌、笔记、导出、存档、更多。建卡指引、扩展管理和配色设置在“更多”中。
- 装备表可左右滑动查看全部信息；每行已增高，便于点选。
- 野兽形态与武术架势页面也随手机宽度排列。需要时从页签旁的“+”开启。
- 导出预览仍为 A4，可左右滑动查看；底部提供打印设置与导出入口。

## 验证

已检查 320、360、390、430、768、844、1023、1024、1440 像素宽布局，触屏选择卡牌、混血/转变开关、资源标记、笔记、装备、额外页面、重载存档及导出预览。另检查手机横屏。

类型检查、项目自动化测试及静态构建通过；彩色/黑白与独立 HTML 的 A4 导出回归检查通过，未出现额外空白页。
